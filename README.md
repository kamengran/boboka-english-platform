# BoBoKa English Learning Platform

BoBoKa English is a web-based English learning platform designed to support structured online English education.

The project includes a public-facing website and a separate learning environment for students, with features for lessons, assignments, practice, progress tracking, and teacher management.

## Project Overview

This project was created to support a complete online English learning workflow, including:

- Public school-style website
- Student learning dashboard
- Course and lesson access
- Vocabulary practice
- Assignment submission
- Audio-based learning activities
- Student progress tracking
- Discussion features
- Teacher management tools
- Learning activity monitoring

The platform is still under active development.

## Repository Scope

This public repository contains the frontend, documentation, and selected project materials for the BoBoKa English Learning Platform.

The backend source code is maintained privately because it includes internal application logic, private project data, student-related data structures, and sensitive configuration.

For privacy and security reasons, backend files, environment variables, databases, and uploaded student content are not included in this public repository.
